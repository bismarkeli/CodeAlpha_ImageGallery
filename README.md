# Interactive Image Gallery

A responsive, feature-rich web-based image gallery built with vanilla HTML5, CSS3, and modern JavaScript. It features dynamic category filtering, a collapsible search bar, an interactive hero image preview, and a full-featured lightbox modal with keyboard navigation.

## Features

- **Category Filtering**: Instantly filter images by categories (Nature, Architecture, Technology, People, and Animals).
- **Interactive Hero View**: Selecting any thumbnail instantly swaps it into the main featured hero display and highlights the active state.
- **Collapsible Live Search**: Click the search icon to expand the search bar and filter images in real-time based on descriptive alt tags.
- **Lightbox Modal**: Click the hero image to view any image in full-screen mode, complete with next/previous navigation buttons, captions, and support for keyboard shortcuts (`Escape`, `ArrowLeft`, `ArrowRight`).
- **Fully Responsive**: Designed with a clean, modern layout that adapts gracefully across different screen sizes.

## Tech Stack

- **HTML5**: Semantic document structure
- **CSS3**: Flexbox layouts, transitions, custom styling, and responsive design
- **JavaScript (ES6+)**: DOM manipulation, event handling, state management for filters and lightbox navigation
